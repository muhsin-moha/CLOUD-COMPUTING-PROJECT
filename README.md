# Portfolio Site

A static personal portfolio (HTML, CSS, vanilla JS — no build step, no framework).

## Files
- `index.html` — page content
- `style.css` — styling
- `script.js` — small scroll-based nav highlight

## Deploying on Render
1. Push this folder to a GitHub repository.
2. In the Render dashboard: **New +** → **Static Site**.
3. Connect the GitHub repo.
4. Build command: leave blank (no build step needed).
5. Publish directory: `.` (repo root) — or the folder these files live in.
6. Click **Create Static Site**. Render will deploy on every push to your default branch.

## Customizing
Replace the placeholder name, bio, projects, and links in `index.html` with your own.
